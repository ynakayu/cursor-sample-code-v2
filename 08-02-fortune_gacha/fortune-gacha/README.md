# 今日の運勢ガチャ

HTMLとJavaScriptで作った、今日の運勢を占うガチャアプリです。

## 機能

- 「ガチャを回す」ボタンをクリックすると、今日の運勢をランダムで抽選します
- 運勢は「大吉」「中吉」「小吉」「吉」「末吉」「凶」「大凶」の7種類から選ばれます
- 抽選中はガチャマシンが揺れるアニメーションと、運勢が次々と切り替わる演出を表示します
- 約2.5秒後に結果が確定し、運勢に合わせたメッセージが表示されます

## ファイル構成

| ファイル | 説明 |
|----------|------|
| `index.html` | 画面の構造とスタイル |
| `main.js` | ガチャの抽選・演出の処理 |

## 使い方

1. `index.html` をブラウザで開きます
2. 「ガチャを回す」ボタンをクリックします
3. 演出が終わると、今日の運勢とメッセージが表示されます

## 動作の流れ

1. ボタンがクリックされる
2. `pickRandomFortune` で最終的な運勢が1つ決まる
3. `startSpinAnimation` で約2.5秒間、運勢が高速で切り替わる（ガチャ演出）
4. `showFinalResult` で確定した運勢とメッセージを表示する

## カスタマイズ

`main.js` の次の定数を変更すると、演出の速さや長さを調整できます。

- `SPIN_INTERVAL_MS` … 運勢が切り替わる間隔（ミリ秒）
- `SPIN_DURATION_MS` … 結果が出るまでの合計時間（ミリ秒）
