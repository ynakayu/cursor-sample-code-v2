# ToDoアプリ

HTMLとJavaScriptで作った、タスクを追加して一覧表示するWebアプリです。

## 機能

- テキストを入力して「追加」ボタンをクリックすると、タスクが一覧に表示されます
- 追加したタスクはリスト形式で表示されます
- 空のまま「追加」した場合は、何も追加されません

## ファイル構成

| ファイル | 説明 |
|----------|------|
| `index.html` | 画面の構造（入力欄・ボタン・タスク一覧） |
| `todo-list.js` | タスクの追加と一覧表示の処理 |

## 使い方

1. `index.html` をブラウザで開きます
2. 「タスク」入力欄にやることを入力します
3. 「追加」ボタンをクリックします
4. 入力した内容が「タスク一覧」に表示されます
5. 続けてタスクを追加する場合は、再度入力して「追加」をクリックします

## 動作の流れ

1. ユーザーがテキストを入力して「追加」ボタンをクリックする
2. `handleAddTaskClick` が入力内容を取得する
3. 入力が空でなければ、`addTaskToList` で `#task-list` に項目を追加する
4. `clearTaskInput` で入力欄を空にする
