# ToDoアプリ

HTMLとJavaScriptで作った、タスクを追加・削除・編集して一覧表示するWebアプリです。

## 機能

- テキストを入力して「追加」ボタンをクリックすると、タスクが一覧に表示されます
- 各タスクの左端にチェックボックスが表示されます
- ページ上部の「完了」ボタンで、チェックを入れたタスクに取り消し線を適用できます
- ページ上部の「削除」ボタンで、チェックを入れたタスクをまとめて削除できます
- タスクのテキストをクリックすると、編集用の入力欄と「編集」ボタンが表示されます
- 「編集」ボタンをクリックすると、タスクの内容が更新されます
- 追加したタスクはリスト形式で表示されます
- 空のまま「追加」した場合は、何も追加されません
- 空のまま「編集」した場合は、内容は更新されません
- チェックを入れずに「完了」した場合は、何も変更されません
- チェックを入れずに「削除」した場合は、何も削除されません

## ファイル構成

| ファイル | 説明 |
|----------|------|
| `index.html` | 画面の構造（入力欄・追加ボタン・完了ボタン・削除ボタン・タスク一覧） |
| `todo-list.js` | タスクの追加・完了・削除・編集と一覧表示の処理 |

## 使い方

1. `index.html` をブラウザで開きます
2. 「タスク」入力欄にやることを入力します
3. 「追加」ボタンをクリックします
4. 入力した内容が「タスク一覧」に表示されます
5. 続けてタスクを追加する場合は、再度入力して「追加」をクリックします
6. タスクの内容を変更したい場合は、一覧に表示されているタスクのテキストをクリックします
7. 表示された編集用の入力欄で内容を直し、「編集」ボタンをクリックします
8. 完了したいタスクの左端のチェックボックスにチェックを入れます
9. ページ上部の「完了」ボタンをクリックすると、チェックしたタスクのテキストに取り消し線が表示されます
10. 削除したいタスクの左端のチェックボックスにチェックを入れます
11. ページ上部の「削除」ボタンをクリックすると、チェックしたタスクだけが一覧から消えます

## 動作の流れ

### タスクの追加

1. ユーザーがテキストを入力して「追加」ボタンをクリックする
2. `handleAddTaskClick` が入力内容を取得する
3. 入力が空でなければ、`addTaskToList` で `#task-list` に項目を追加する
4. 各項目にはチェックボックス、タスクの文字列、編集用の入力欄と「編集」ボタンが含まれる
5. `clearTaskInput` で入力欄を空にする

### タスクの編集

1. ユーザーがタスクのテキストをクリックする
2. `handleTaskTextClick` が `hideAllTaskEditForms` で他の編集フォームを閉じる
3. `showTaskEditForm` で対象タスクの編集用入力欄と「編集」ボタンを表示する
4. ユーザーが内容を直して「編集」ボタンをクリックする
5. `handleEditTaskClick` が入力内容を取得する
6. 入力が空でなければ、`updateTaskText` でタスクの文字列を更新する
7. `hideTaskEditForm` で編集フォームを非表示にし、更新後のテキストを表示する

### タスクの完了

1. ユーザーが完了したいタスクのチェックボックスにチェックを入れる
2. ページ上部の「完了」ボタンをクリックする
3. `handleCompleteTasksClick` が `completeCheckedTasks` を呼び出す
4. `getCheckedTaskListItems` でチェックが入った項目だけを集める
5. `applyCompletedStyleToTask` で各タスクのテキストに取り消し線を適用する

### タスクの削除

1. ユーザーが削除したいタスクのチェックボックスにチェックを入れる
2. ページ上部の「削除」ボタンをクリックする
3. `handleDeleteTasksClick` が `deleteCheckedTasks` を呼び出す
4. `getCheckedTaskListItems` でチェックが入った項目だけを集める
5. 集めた項目を `#task-list` から取り除く
