# パスワードジェネレーター

HTMLとJavaScriptで作った、ランダムなパスワードを生成するWebアプリです。

## 機能

- 「パスワードを生成する」ボタンをクリックすると、12文字のランダムなパスワードを生成して表示します
- 英大文字・英小文字・数字・記号（`!@#$%^&*`）を組み合わせて生成します

## ファイル構成

| ファイル | 説明 |
|----------|------|
| `index.html` | 画面の構造 |
| `main.js` | パスワード生成の処理 |

## 使い方

1. `index.html` をブラウザで開きます
2. 「パスワードを生成する」ボタンをクリックします
3. 画面上に生成されたパスワードが表示されます

## 動作の流れ

1. ボタンがクリックされる
2. `generateRandomPassword` が12文字のパスワードを作る
3. `displayPassword` が画面の `#password-display` に結果を表示する
