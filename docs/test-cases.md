# 勉強時間トラッカー テストケース

## テスト概要

| 項目 | 内容 |
|------|------|
| 対象アプリ | 勉強時間トラッカー（`index.html` + `app.js`） |
| 目的 | タイマー計測・手動記録・LocalStorage 永続化・カレンダー表示・日別履歴表示が仕様どおり動作することを確認する |
| テスト種別 | 手動機能テスト（ブラウザ操作） |
| 対象外 | 自動化テストコード、CSS の視覚的デザイン詳細、他ブラウザ間の微妙な差異 |

### テストケース件数

| カテゴリ | 件数 |
|----------|------|
| 機能テスト | 22 |
| LocalStorage テスト | 14 |
| カレンダー表示テスト | 14 |
| 学習履歴表示テスト | 14 |
| 異常系テスト | 16 |
| **合計** | **80** |

## 前提条件・テストデータ

### 共通前提条件

1. ブラウザで `index.html` を開く（ローカルファイルまたは簡易 HTTP サーバー）
2. 開発者ツール（Application → Local Storage）で `studyTimeApp.v1` を確認・操作できること
3. システム日時が正しく設定されていること（「今日」の判定・日付入力の初期値に影響）
4. 各テスト前に必要に応じて LocalStorage をクリアする（テスト間の干渉防止）

### テストデータ

#### 正常系：タイマー記録用入力

| 項目 | 値 |
|------|-----|
| 科目（`#subjectInput`） | 数学 |
| トピック（`#topicInput`） | 微分積分 |
| メモ（`#notesInput`） | 演習問題 1〜10 |

#### 正常系：手動記録用入力

| 項目 | 値 |
|------|-----|
| 日付（`#manualDateInput`） | 2026-05-20 |
| 勉強時間（分）（`#manualMinutesInput`） | 45 |
| 科目 / トピック / メモ | 上記タイマー用と同じ |

#### LocalStorage 直接投入用サンプル（正常）

```json
{
  "version": 1,
  "sessions": [
    {
      "id": "test-session-1",
      "date": "2026-05-20",
      "subject": "英語",
      "topic": "リスニング",
      "notes": "過去問",
      "durationMs": 1800000,
      "startedAt": "2026-05-20T10:00:00.000Z",
      "endedAt": "2026-05-20T10:30:00.000Z",
      "source": "timer"
    }
  ],
  "activeTimer": null
}
```

#### LocalStorage 直接投入用サンプル（実行中タイマー）

```json
{
  "version": 1,
  "sessions": [],
  "activeTimer": {
    "startedAt": "2026-05-23T01:00:00.000Z",
    "subject": "物理",
    "topic": "力学",
    "notes": "",
    "accumulatedMs": 0,
    "pausedAt": null
  }
}
```

#### LocalStorage 直接投入用サンプル（一時停止中タイマー）

```json
{
  "version": 1,
  "sessions": [],
  "activeTimer": {
    "startedAt": null,
    "subject": "化学",
    "topic": "有機化学",
    "notes": "復習",
    "accumulatedMs": 120000,
    "pausedAt": "2026-05-23T02:00:00.000Z"
  }
}
```
