# 文字数カウンター

テキスト入力欄に入力した文字数を、ボタンクリックでカウントして表示するシンプルなWebページです。

## 機能

- テキスト入力欄と「文字数をカウント」ボタンを表示
- ボタンをクリックすると、入力内容の文字数を表示

## ファイル構成

| ファイル | 説明 |
|----------|------|
| `index.html` | ページの構造 |
| `main.js` | 文字数カウントの処理 |

## 使い方

1. `index.html` をブラウザで開く
2. テキスト入力欄に文字を入力する
3. 「文字数をカウント」ボタンをクリックする
4. 入力した文字数が画面に表示される

## 技術

- HTML5
- JavaScript（Vanilla JS）
